# Guion para demostrar Clima en Casa

**Duración aproximada:** 1 a 2 minutos.

1. Abre la app y muestra la búsqueda inicial de Ciudad de México.
2. Busca otra ciudad, por ejemplo, Monterrey. Si aparecen varias opciones, elige una para mostrar cómo se resuelve una coincidencia.
3. Explica que OpenMeteoService consulta primero la API de geocodificación para obtener coordenadas y después la API de pronóstico para obtener los datos actuales y los próximos cinco días.
4. Señala la temperatura, humedad, sensación térmica, viento y probabilidad de lluvia. Menciona que la interfaz traduce los códigos meteorológicos a descripciones.
5. Busca un nombre de ciudad inexistente para mostrar el estado sin resultados. Para explicar el error de conexión, puedes desconectar temporalmente el emulador de internet, actualizar y luego volver a conectarlo.
6. Cierra explicando que usaste Codex (GPT-6) para construir y revisar la app, y que las respuestas provienen de Open-Meteo. El proyecto no usa una clave de API.
